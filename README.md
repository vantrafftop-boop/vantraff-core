## 🌟 Overview

**VANTRAFF** is a robust alternative to legacy traffic exchanges and automated bots. Designed for webmasters and SEO professionals who value real audience engagement, structural transparency, and deep technical metrics without artificial inflation.

## 🛠 Core Architecture & Features

*   **Real User Traffic Exchange:** Eliminates dead bots and dummy scripts, driving genuine interaction with configurable visit sessions (3, 6, 9 steps).
*   **SEO Audit 360° Engine:** Deep automated scanner that evaluates site metrics, server health, schema markup, and calculates asset valuation based on real technical factors.
*   **Security & Anti-Fraud:** Built-in safeguards against malicious traffic, scraping, and suspicious headers.
*   **Optimized Backend:** Fast PHP implementation with optimized database queries and strict HTML entity decoding for flawless metadata generation.

## 📂 Project Structure

- `/core` - Core business logic, routing, and controller scripts.
- `/includes` - Modular layout elements (header, footer, security filters).
- `/assets` - Frontend styles, icons, and branding assets.
